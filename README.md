# PDF to CSV Parser

A Python utility that extracts data from multiple PDF files
and combines the extracted information into a single CSV file.

## What does this project do?

This program:

1. Reads PDF files from an input folder.
2. Extracts the required information from each PDF.
3. Combines the extracted information.
4. Generates a single CSV file containing the results.

The program was tested successfully using multiple PDF files.

### Setup Instructions

1. **Create a main folder** for the project.

2. Inside the main folder, create a subfolder named **`PDF`** (or a similar name). This folder will be used to store all your PDF files.

3. **Download the Python code file** and place it inside the main folder.

4. Before running the code, you can **customize any parts of it** according to your needs. I’ll show you, using screenshots, which sections of the code can be modified.

5. Place all the **PDF files you want to process** inside the `PDF` subfolder.

6. **Important:** Make sure all the PDF files follow the **same format and structure**. Inconsistencies between the files may prevent the code from working correctly.

Once everything is organized, you can run the Python code from the main folder.
